# Rick and Morty Explorer

## Descripción
Una aplicación web para explorar los personajes del universo de Rick and Morty, haciendo uso de la API oficial.

## Integrantes
- Persona 1: Santiago Aylagas

## Tecnologías Utilizadas
- HTML5 Semántico
- CSS3 (Variables, Grid, Flexbox, Media Queries)
- JavaScript (Próximamente)

## Instrucciones para ejecutar
1. Clona este repositorio en tu máquina local.
2. Abre el archivo `index.html` en tu navegador web preferido. No se requiere servidor web.
